# FAQ — Cabañas El Capitan

Página de preguntas frecuentes con acordeón interactivo.

## Componentes de esta pantalla

### PageBanner
- Breadcrumb: Inicio > FAQ
- Título: "Preguntas Frecuentes"

### FaqAccordion
- 4 categorías con múltiples items:

#### Reservas (4 items)
- ¿Cómo reservar?
- Pago anticipado (50%)
- Antelación de reserva (1 semana)
- Capacidad de cabañas

#### Check-in y Check-out (3 items)
- Horario de check-in (2:00 PM)
- Horario de check-out (12:00 PM)
- Disponibilidad del personal (7AM-9PM)

#### Servicios (4 items)
- Desayuno (opcional)
- Piscina (compartida, 8AM-8PM)
- Tours
- WiFi (gratuito)

#### Cancelaciones y modificaciones (2 items)
- Cancelación (72h de antelación)
- Cambio de fechas (48h de antelación)

### FaqCta
- "¿No encontraste lo que buscabas?"
- Link a página de contacto
